A lightweight starter plugin for WP Control Deck.

== Description ==

WP Control Deck is a custom WordPress plugin by Vincent Casilla.

This release adds a WP Control Deck admin menu with controls to disable WordPress comments globally and permanently delete existing comments.

== Installation ==

1. Upload the `wp-control-deck` folder to the `/wp-content/plugins/` directory.
2. Activate WP Control Deck through the Plugins screen in WordPress.
